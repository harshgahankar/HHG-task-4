## LinkedIn Post

```
Excited to share our submission for the TigerGraph Agentic Fraud Investigation Hackathon!

We built an end-to-end agentic system that:

1. Ingests 590,742 transactions into a graph database
2. Investigates fraud alerts through a state-machine agent
3. Detects fraud patterns using graph algorithms (PageRank, Louvain, WCC)
4. Applies a 10-rule policy matrix with approval routing
5. Produces complete investigation records with regulatory SAR filings

Key results:
- 20/20 benchmark cases validated
- 100% policy compliance (no unauthorized actions)
- ~12s average investigation latency
- GraphRAG pipeline for evidence synthesis

The graph revealed fraud rings invisible in flat tables - device profiles linking multiple compromised cards across customers.

Built with:
- TigerGraph (graph backend)
- FastAPI (Python backend)
- React (frontend)
- NetworkX (graph algorithms)

Thank you @TigerGraphDB for this challenge!

#FraudDetection #GraphDatabase #AgenticAI #TigerGraph #Hackathon
```
